# Historical NightAzimuth Documentation

This directory contains documents preserved for project history.

They are **not current product instructions**.

- `stages/` contains historical Stage 1–21 implementation/requirements/prototype documents from the desktop-to-hosted transition.
- `releases/` contains historical desktop-era release-note source files.

The current product documentation lives one level up in `docs/`.

Use archived files when investigating why a feature or architecture decision was made, not as the normal user/deployment guide.
