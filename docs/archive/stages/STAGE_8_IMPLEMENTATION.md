# Stage 8 — Live View Refinement

Status: Approved for merge

Created by Logic Lurker © 2026

## Scope

Stage 8 refines the forward-looking Live view for practical human observing while leaving the all-sky Sky map unchanged.

Implemented:

- practical Live view elevation range of 0–60°
- horizontal reference lines at 10° intervals
- mouse-wheel zoom
- + / − zoom controls
- drag-to-select rectangular zoom region
- Reset view control
- continued real-time satellite updates while zoomed
- indication/counting for tracked objects outside the current vertical view
- existing facing direction and horizontal field-of-view controls retained

The all-sky Sky map remains unchanged and continues to show the full 0–90° hemisphere.

## Rationale

The Live view is intended for a person standing outdoors and looking in a chosen direction. A 0–60° elevation range gives more screen space to the part of the sky that is generally comfortable to observe for sustained periods, while the full astronomical hemisphere remains available in the Sky map tab.

## Deferred

Stage 8 does not add:

- projected future tracks
- direction-of-travel arrows
- brightness/magnitude modelling
- weather or cloud analysis
- camera integration
- aircraft or meteor matching

These remain for later approved stages.
