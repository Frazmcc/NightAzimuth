## Historical documentation

Historical implementation stages, prototype documents and desktop-era release notes are kept under [`archive/`](archive/).

Those files are preserved for development history. They may describe old Windows/Tkinter behaviour, old release processes, superseded architecture or capabilities that have since moved to the hosted web application.

Do not use archived documents as current installation or operations guidance unless you are deliberately investigating project history.
